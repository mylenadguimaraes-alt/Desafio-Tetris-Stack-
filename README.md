# Tetris Stack

## Sobre o Projeto

Tetris Stack é um projeto desenvolvido em linguagem C++ inspirado no sistema de gerenciamento de peças do jogo Tetris. O programa simula a organização e manipulação de peças utilizando duas estruturas de dados fundamentais: fila e pilha.

O objetivo do projeto é demonstrar o funcionamento dessas estruturas através de operações de inserção, remoção, reserva de peças e trocas estratégicas entre a fila principal e a pilha de reserva.

## Funcionalidades

- Geração automática de peças com identificadores únicos.
- Fila circular para armazenamento das próximas peças.
- Pilha de reserva para guardar peças temporariamente.
- Utilização de peças da fila.
- Envio de peças para a reserva.
- Recuperação de peças armazenadas na reserva.
- Troca da peça da frente da fila com o topo da pilha.
- Troca dos três primeiros elementos da fila com os três elementos da pilha.
- Exibição em tempo real do estado da fila e da pilha.

## Como Executar

### Utilizando o Executável

1. Baixe o arquivo `Tetris_Stack.exe`.
2. Execute o programa.
3. Utilize o terminal para interagir com as estruturas de dados.

### Compilando o Código-Fonte


gcc Tetris_Stack.c -o Tetris_Stack


Para executar:


./Tetris_Stack


No Windows:


Tetris_Stack.exe
